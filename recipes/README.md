# Recipes

Composable deployment and sample layouts (for example Docker Compose stacks) that illustrate patterns from the main platform.

## Repository

These paths are part of the upstream monorepo:

```bash
git clone https://github.com/SentinelOps-CI/provability-fabric.git
cd provability-fabric/recipes
```

## Layout

| Path | Description |
|------|-------------|
| [saas-egress-guard](saas-egress-guard/) | SaaS-style egress guard sample (`saas-app/`, `docker-compose.yml`) |
| [retrieval-guard](retrieval-guard/) | Retrieval guard Compose stack |

Adjust images, networks, and secrets for your environment before using in production.
