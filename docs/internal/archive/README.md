# Internal archive

Historical audits, delivery checklists, and status snapshots that are **not** live truth.

## Policy

1. **Live status** lives in [`../remediation-tracker.md`](../remediation-tracker.md) (findings / waves) and [`../../roadmap/evidence-program-closure.md`](../../roadmap/evidence-program-closure.md) (gated CI posture).
2. Documents here are preserved for audit trail and link stability. Do not cite their CI counts (for example 8/67 or 13/68) as current.
3. Prefer updating the tracker or program-closure page over editing archived snapshots.
4. When a living doc becomes a completed status stamp, move it here and leave a short stub or redirect at the old path if external links matter.
